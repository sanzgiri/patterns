# Guided Tutorial

This is the self-paced teaching track for the pattern reference. Every lesson follows:

1. **Lesson** — concepts and mental models
2. **Worked example** — how a company might apply them
3. **Practice** — questions and design exercises
4. **Interview drill** — timed application

## 21-week path

| Phase | Weeks | Focus |
|---|---:|---|
| Foundations | 1–4 | Requirements, storage, distribution, consistency |
| Reliable services | 5–8 | Messaging, workflows, resilience, operations |
| LLM foundations | 9–12 | Interfaces, retrieval, context, workflows |
| Production agents | 13–16 | Orchestration, evals, security, rollout |
| Breadth pass | 17–21 | Remaining system and agent patterns |
